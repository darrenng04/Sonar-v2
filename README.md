# Sonar 🎵
Navigating Your Social Life Through The Sounds That You Love

A music-taste-based nightlife discovery iOS app built with SwiftUI and Claude AI.

## Features
- Personalized venue matching based on your Music taste
- AI-powered nightly briefing and chat assistant
- Real-time match scores for venues and people 
- Profile with genre preferences and energy settings

## Built With
- SwiftUI (iOS)
- Anthropic Claude API
- Xcode 16

## Status
In development — Yelp API integration coming soon.
